RESUMO DO PROJETO - TumaIA

O TumaIA é uma plataforma SaaS WhatsApp-first para pequenas e médias empresas produzirem conteúdo para Instagram com mais velocidade e consistência. Em vez de montar cada post do zero (texto, arte, hashtags e publicação), a empresa pede o conteúdo pelo WhatsApp ou pelo painel web; o sistema carrega o contexto da marca, gera imagem e legenda com IA, pede aprovação humana e só então publica no Instagram.

PROBLEMA QUE O PROJETO RESOLVE

Muitas PMEs não conseguem manter constância nas redes porque:
- Falta tempo para produzir conteúdo com frequência.
- Criar posts de qualidade exige escrita, design e planejamento.
- O processo manual vira gargalo de marketing.

COMO O TumaIA FUNCIONA (fluxo real)

1. A empresa cadastra no painel (Next.js) identidade de marca, produtos, mídias e objetivos.
2. O pedido de post chega pelo WhatsApp (Cloud API da Meta) ou pelo chat do painel.
3. O backend Node.js (Express) identifica a empresa, carrega o contexto no Supabase e interpreta a intenção (conversa, acervo, empresa ou pedido explícito de imagem).
4. A IA gera proposta de post (imagem + legenda/hashtags) alinhada à marca.
5. O usuário aprova ou pede ajustes (aprovação humana obrigatória).
6. Com aprovação, o próprio backend publica no Instagram via Meta Graph API.

Não há orquestrador externo (n8n) no turno a turno: webhook WhatsApp → monólito Node → Supabase → provedores de IA → Meta Graph.

O QUE JÁ FAZ PARTE DO PROJETO

- Integração WhatsApp Cloud API (Meta) com webhook no backend.
- Painel Next.js para marca, acervo, chat e fluxo de arte.
- API monólito Node.js Express (auth, empresas, chat, IA, WhatsApp, Instagram).
- Dados e autenticação no Supabase (Postgres, Auth, Storage).
- Chat conversacional em Node (TUMAIA_NODE_CHAT=true): regras + analyzeChatTurn/processChatMessage; Ollama ou LLM cloud em exceções. Python/RAG/Chroma em backend/ia/python/ é legado, fora do caminho feliz.
- Geração de imagem configurável (IMAGE_PROVIDER): OpenAI gpt-image-2 ou Replicate.
- Publicação Instagram via Meta Graph no backend após aprovação.

RESULTADO ESPERADO

Com o TumaIA, a empresa consegue:
- Produzir conteúdo com mais frequência.
- Manter padrão visual e de comunicação.
- Reduzir horas operacionais por semana.
- Focar mais em estratégia e menos em tarefas repetitivas.


FLUXO EM PASSOS (visão simples)

Cliente pede um post
Pelo WhatsApp ou painel.

Sistema identifica a empresa
Telefone + workspace ativo (WhatsApp) ou JWT + id_empresa (painel).

Sistema monta o contexto da marca
Nome, cores, logo, tom, acervo e o pedido do usuário (Supabase).

Roteamento de intenção (Node)
tumaInterpretation + chatTurnIntent + processChatMessage
decidem: conversa, acervo, dados da empresa ou geração explícita de imagem.

IA gera texto e imagem
Legenda/hashtags e prévia de arte (OpenAI ou Replicate conforme IMAGE_PROVIDER).

Aprovação humana
Usuário confirma, ajusta legenda/imagem ou pede nova versão.

Publicação
Backend publica no Instagram via Meta Graph API.

Resumo em 1 frase:
Recebe pedido → carrega marca no Supabase → IA gera post → aprovação → Instagram.


STACK ATUAL (produto)

Painel: Next.js (frontend/).
API: Node.js Express monólito (backend/src/).
Dados: Supabase (Postgres, Auth, Storage).
Chat: motor Node (regras + estados + LLM em exceções); Python/RAG legado opcional.
WhatsApp: Cloud API Meta (webhook no backend).
Instagram: Meta Graph API no backend após aprovação.
Imagem: IMAGE_PROVIDER = OpenAI gpt-image-2 ou Replicate.
Roteamento: tumaInterpretation + chatTurnIntent + processChatMessage.
