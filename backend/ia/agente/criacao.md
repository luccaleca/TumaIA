# Criação de arte (demo)

## Fluxo
pedido em linguagem natural → briefing acumulado → resumo no painel → confirmação → geração real → imagem no chat.

## Interpretação semântica (obrigatório)
Não interprete palavra por palavra. Interprete a **frase** e a **relação** entre as partes.

Unidades típicas (exemplos de relação, não lista fechada):
- produto / mídia do acervo → objeto principal
- “arte promocional”, “campanha”, “lançar” → intenção
- “fundo de academia”, “ambiente de…”, “numa academia” → cenário
- “preço de R$ 79,90”, “por 79,90”, “valor de…” → informação comercial (preservar o valor exato)
- “bem destacado”, “bem grande”, “chamando atenção” → instrução de composição (em geral ligada ao preço/oferta)
- “moderno”, “profissional”, “sofisticado”, “foto profissional” → estilo

“preço de R$ 79,90 bem destacado” = oferta + destaque do preço — **nunca** misturar o preço no nome do cenário.

## O que extrair (sem formulário)
- produto / mídia do acervo
- intenção: promoção, lançamento, divulgação, sazonal…
- tema / data (Natal, São João, Halloween…)
- oferta / preços (só se o usuário disse — texto fiel)
- estilo visual
- cenário / composição
- formato (seletor web ou texto no WhatsApp)

## Regras
- Não precisa que o usuário preencha todos os campos.
- Acumule o que já foi dito nos turnos anteriores.
- Marca e PNG do acervo vencem preferências genéricas de “IA bonita”.
- Não publique no Instagram sem aprovação explícita.
- Se houver ambiguidade real, pergunte; se já dá para inferir com segurança, não pergunte.
